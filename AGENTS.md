# Calvin Autonomy workspace

Keep shared code and documentation generic. Student coursework, memory, logs, and generated runs belong under `workspace/` and remain private. Read original assignments before planning; course evidence controls methods and formats. Preserve originals, use hashes and locators, leave uncertain evidence unresolved, and never execute imported code or spreadsheet macros. Run `PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -v`.

When a course is first added or its conventions change, use the `build-course-profile` skill and course-profile curator. Bind every reusable method or format rule to an exact durable evidence review; visual conventions require page inspection.

When a student supplies an assignment and asks for completion, use the `complete-assignment` skill. Retrieve only same-course evidence, match reviewed prior examples, create an adaptation manifest for any match, and complete every current requirement with fresh inputs and checks. Use `[Student Name]` and `[Student ID]` unless the student explicitly supplies identity for that private run. Run the assignment verifier and visually inspect every rendered artifact before reporting it ready.
