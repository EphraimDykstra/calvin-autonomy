# Header-style memo: executive-summary shape

Shape only. This is the To/From/Date/Re form, seen in one course (ENGR 322). Use it only when the assignment asks for this form. Every value below is a placeholder or an invented stand-in.

---

| | |
|---|---|
| **To:** | [Recipient, as the assignment names it] |
| **From:** | [Student Name] |
| **CC:** | [If the assignment asks for one] |
| **Date:** | [Date] |
| **Re:** | [Short subject: which problem or analysis this summarises] |

The first paragraph gives the answer: the design value or the decision, and the conditions it assumes. For example: "A 12 mm pin in the stand-in bracket carries the load, with no safety factor applied."

The second paragraph says how the answer was checked, and how closely the checks agree. For example: "A hand calculation and an FEA model agree within 6 %; the FEA peak at a sharp corner was set aside as a mesh artifact."

The third paragraph covers approximations and which direction they push the answer.

Close with a one-line statement of confidence in the result, or a recommendation.

Supporting work goes on the pages that follow, or in attachments, if the assignment asks for it: hand calculations, the FEA setup, and results tables with units.

---

Notes:

- Keep it to about one page of prose.
- In this course the instructor's own model summary uses first person. That is not the rule in the thermo-fluids courses, so follow the course.
