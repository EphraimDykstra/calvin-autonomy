---
name: manage-student-memory
description: Maintain small, inspectable project-scoped student preferences and run handoffs without replacing course evidence.
---

Use `memory list`, `memory set`, and `memory forget` for durable preferences and continuation notes. Record date, scope, and source. Store pointers to course evidence rather than duplicating equations or unsupported rules. Never infer sensitive ability assessments. A memory entry cannot override current assignment instructions, current course evidence, or explicit user direction; stale or contradicted entries must be retired. Keep updates inside the project workspace and never write them into the shareable framework.
